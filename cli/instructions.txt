Use the named device; never substitute another when offline. Never use host ADB. Pass device if multiple are linked.
- Sessions (`android.task`): `begin` (private default; optional `package`/`url`/`intent`/`join`; `mode:foreground`+`confirmed:true` for main screen), `inspect`, `list`, `finish`, `share`, `handoff` (`confirmed:true`), `record_start`/`record_stop`/`record_status`.
- UI: `observe` returns compact 1-line controls and auto-diffs (`full:true`, `detail:debug`, `image:always|if_needed|only`, `windowId`). UI actions also accept `verify`, `image`, `observe`, `windowId`, `timeoutMs`, `full`, `detail`, `timing`. `selector`: `{label?,resourceId?,role?,context?}`. `verify`: `{conditions:[{kind:exists|absent|appeared|field|state|window|stable,...}],match?:all|any}`. Batch consecutive tap/type/key steps with `sequence` (up to 12 steps; `"previous"`/`"step:0"`, `optional:true`).
- Writes: `requestId` is auto-generated (pass one only to deduplicate explicit retries); never retry unknown writes without checking state. Blocked apps return `code=blocked_app`; use `confirm` for Approve/Take Over/Cancel.
- Files (`android.file`): `pull` (auto single-call for >1 MiB), `push`, `fetch`. Utilities (`android.device`): `clipboard`, `media`, `location`, `control`, `audio`.
